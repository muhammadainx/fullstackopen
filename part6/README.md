# Part 6: Advanced state management

This section implements advanced patterns for managing application state in large-scale React applications. It covers the transition from local component state to global management using Redux Toolkit, emphasizing Flux architecture principles, centralized store configuration, and the professional use of reducers and action creators.

The module also integrates asynchronous state management, utilizing Redux Thunk for complex logic and React Query (TanStack Query) for efficient server-state synchronization, automated caching, and data fetching. Additionally, it compares these tools against the Context API and useReducer hook, providing a comprehensive framework for selecting the optimal state strategy based on application scale and complexity.
